# Atomic Artillery 2 Reborn

Yet another resurrection of SirDoombox's original Atomic Artillery ([source](https://github.com/sirdoombox/AtomicArtillery), [portal link](https://mods.factorio.com/mod/AtomicArtillery)) mod for Factorio, subsequently maintained by both Kommade as Atomic Artillery 2 ([source](https://github.com/kommade/AtomicArtillery), [portal link](https://mods.factorio.com/mod/AtomicArtillery2)) and SergiX44 as Atomic Artillery Reborn ([portal link](https://mods.factorio.com/mod/atomic-artillery-reborn)).

This is a Factorio mod which adds artillery shells with atomic warheads.

## Really, Another Fork?

Yes. Neither Kommade nor SergiX44 have updated their mods to support 2.1 yet. I'll try to raise a PR to Kommade's repo at the end of this. If either of these folks resume upkeep, I'll probably retire this mod.

## But 2.1 Has This Mod!

No, not really. While I know there are other variants of 'atomic artillery' for 2.1 already, I prefer this mod variant over its alternatives.

## A Hodgepodge

This variant uses Kommade's fork as the base, merging in a few tweaks from SergiX44's Atomic Artillery Reborn.
